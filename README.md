Define Word is now maintained in [Zen-Mods/define-word](https://github.com/YiftahCooper/Zen-Mods/tree/main/define-word).

For a fresh install, paste this individual folder URL into Sine's GitHub installation field:

```text
https://github.com/YiftahCooper/Zen-Mods/tree/main/define-word
```

The files in this repository remain the historical 0.1.1 source. Its transition manifest points Sine to the maintained folder; this repository is retained temporarily and may later be archived.
